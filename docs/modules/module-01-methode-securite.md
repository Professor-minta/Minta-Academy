# Module 1 – Méthode de travail numérique & Sécurité

**Durée :** 21–22 minutes  
**Objectif :** Mettre en place une méthode de travail propre et des règles de sécurité solides.

## Contenu du module

- Pourquoi la méthode avant la technique
- Organisation des dossiers (structure recommandée)
- Création et sécurisation du compte GitHub + 2FA
- Les 5 règles de sécurité absolues
- Exercice pratique

## Exercice obligatoire

1. Créer le dossier principal de travail avec les sous-dossiers
2. Créer / sécuriser un compte GitHub avec 2FA
3. Créer un dépôt privé `minta-academy-notes`
4. Écrire dans le README : « Je suis [Prénom], étudiant Minta Academy. J’ai terminé le Module 1. »
