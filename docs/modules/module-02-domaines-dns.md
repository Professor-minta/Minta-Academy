# Module 2 – Domaines & DNS (Namecheap)

**Durée :** 20–21 minutes  
**Objectif :** Savoir chercher, acheter et configurer un nom de domaine.

## Contenu du module

- Pourquoi le domaine est important
- Recherche et choix d’un bon nom de domaine
- Achat sur Namecheap + activation WhoisGuard
- Comprendre les enregistrements DNS (A et CNAME)
- Préparer le domaine pour le VPS

## Exercice obligatoire

1. Acheter ou configurer un domaine
2. Activer WhoisGuard et 2FA
3. Créer le fichier `module-2-domaine.md` dans ton dépôt notes
