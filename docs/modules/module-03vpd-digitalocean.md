# Module 3 – Serveur VPS & DigitalOcean

**Durée :** 24–26 minutes  
**Objectif :** Créer et sécuriser un Droplet Ubuntu.

## Contenu du module

- Création d’un Droplet Ubuntu
- Connexion SSH avec clé
- Création d’un utilisateur non-root + sudo
- Configuration du firewall UFW
- Mise à jour du système

## Exercice obligatoire

1. Créer un Droplet
2. Créer un utilisateur non-root
3. Activer UFW (OpenSSH autorisé)
4. Créer le fichier `module-3-vps.md`
